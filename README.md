# 기린서버 생활 계산기

기린서버 생활 직업용 계산기 모음

- `index.html` — 첫 화면 (권한에 따라 카드가 보여요)
- `enhance.html` — 강화 기대값 계산기 (누구나)
- `market.html` — 요리 재료 거래소 (농부·어부 판매, 요리사 품목별 부분 구매)
- `cooking.html`, `alchemy.html` — 요리사·연금술사만 열리는 계산기 (본체는 Supabase 비공개 저장소)
- `admin.html` — 운영자 페이지
- `config.js` — Supabase 주소와 공개 키
- `auth.js` — 공통 로그인·권한 처리
- `fonts/do-hyeon-site.woff2` — 제목 글꼴 (사이트에 쓰이는 글자만)
